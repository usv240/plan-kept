# Plan Kept: Prior Art and Differentiation

| Existing area | Existing capability | Plan Kept’s bounded contribution |
|---|---|---|
| Incident reporting | Capture event details, forms, attachments, workflows | Starts from existing support promises, not an incident |
| Debrief | Collect student/staff accounts and follow-up | Separate sharing controls plus promise-linked evidence |
| Notifications/actions | Assign, remind, and audit work | Return each repair to student experience before closure |
| Behavior analytics | Trends, dashboards, intervention insights | Explicitly refuses danger, credibility, blame, or discipline scores |
| Plan generation/management | Draft and store support documents | Reads only existing promises and cannot alter the plan |

RecordHQ, Cairn, and MangoApps helped remove a crowded “AI incident debrief” center from the idea.
Our narrower claim is a privacy-aware promise-to-reality ledger with conflict-driven clarification
and lived-experience repair confirmation.

No public-search process proves global uniqueness, so the project avoids “world’s first” language.
